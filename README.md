# 农场小助手

农场小助手是一个用于微信小程序 QQ 经典农场相关操作的安卓辅助工具。它通过悬浮窗提供快捷控制，可以在需要时启动自动化脚本，减少重复点击操作。

> 免责申明：本程序基于纯视觉运行，不涉及读取计算机内部文件、篡改游戏内部数据。建议仅用于个人学习和自用。

## 主要功能

- 悬浮窗快捷控制：开始、暂停、停止脚本。
- 悬浮窗日志：查看当前脚本运行状态。
- 脚本切换：支持在悬浮窗配置界面选择不同功能。
- 坐标抓取：可在悬浮窗内抓取并保存需要点击的位置。

当前支持的脚本：

- 自动偷菜
- 自动加好友

## 使用前准备

安装 App 后，需要开启两个权限：

1. 悬浮窗权限  
   用于显示控制按钮、日志和配置界面。

2. 无障碍权限  
   用于执行截图识别、点击和滑动操作。

## 使用方法

1. 打开“农场小助手”。
2. 点击“启动悬浮窗”。
3. 如果系统提示需要权限，按提示开启悬浮窗权限。
4. 回到 App，点击“跳转无障碍设置”。
5. 在系统无障碍设置中开启“农场小助手”。
6. 回到需要操作的页面。
7. 在悬浮窗中打开配置界面，选择要运行的功能。
8. 点击悬浮窗的开始按钮运行脚本。

## 自动偷菜

第一次使用自动偷菜前，建议先进入悬浮窗配置界面，依次设置需要点击的位置。

配置时点击对应项目的“抓取”按钮，然后在屏幕上点击实际位置即可保存坐标。

## 自动加好友

选择“自动加好友”后，脚本会自动识别页面中的好友卡片，并按流程点击和关闭相关页面。

如果页面识别不到目标内容，脚本会自动滑动页面继续查找；如果连续无法完成关闭识别，脚本会暂停，避免一直误操作。

## 常见问题

### 悬浮窗没有出现

请检查是否已经开启悬浮窗权限，然后重新点击“启动悬浮窗”。

### 点击开始后没有反应

请检查是否已经开启“农场小助手”的无障碍权限。

### 点击位置不准

请重新进入悬浮窗配置界面，重新抓取对应坐标。

### 识别不准确

游戏界面变化、分辨率变化、动画未结束等情况都可能影响识别。可以稍等页面稳定后再运行脚本。

## 下载和安装

下载后在手机上安装即可。部分手机可能会提示“未知来源应用”，按系统提示允许本次安装即可。
